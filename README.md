# kimiMoonSlop
Kimi MoonShot? More like Kimi MoonSlop

## Description
A simple clicker game where the only thing that is festivalized is the button, that's it. Do not expect too much as this is my first web project.

## How it's made
Since in the past I have already vibecoded a bunch of web pages and automation script, I felt like why not learn how to implement web pages myself? With that in mind, I went off with typescript, css and html, and asked AI for hints and guidance instead of giving me answers.

That's why it's called kimiMoonSlop, because instead of being Artificial Intelligence Slop, it becomes Actual Intelligence slop

Hope someone enjoyes my site, this is probably going on Cloudflare Pages.
